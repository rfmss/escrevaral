# Decisão 001 — Uma Mesa antes do sistema inteiro

Data: 14/10/2026. Estado: aplicada ao lote R01-Mesa. Autoridade: Rafa autorizou começar, assumir riscos baratos, evitar testes excessivos e manter diário para continuidade por qualquer IA.

## Escopo fechado

A primeira entrega deve escrever, guardar, reabrir, recuperar uma cópia e exportar texto simples. O Gabinete completo e os motores entram depois. A árvore nova fica em `reconstrucao`; produção e vault permanecem intactos. O primeiro commit pode ter o SHA do vault como pai para conservar a rastreabilidade, mas sua árvore de trabalho é nova e seletiva.

## Hipóteses, não decisões definitivas

Texto simples foi escolhido para validar escrita e persistência. O autor ainda não decidiu entre edição com marcação e edição visual rica; não interpretar o início do projeto como aprovação definitiva do formato. `.txt` é a exportação inicial; pacote `.scrvrl` e importação antiga dependem do contrato de acervo.

LocalStorage é um adaptador pequeno para esta fatia, não a decisão final para acervo grande. O plano anterior propunha IndexedDB após prova real. Essa prova continua pendente; a porta de armazenamento evita acoplar a interface a uma implementação. Não anunciar os dois adaptadores como entregues.

A estética usa papel #CCD5C7, tinta #1E2320 e uma superfície clara derivada, linhas e Georgia nativa. A busca de paridade com todos os detalhes aprovados continua no inventário. O anexo é referência de aparência e interação; promessas de CPU/perda zero, comprovação humana por hash e efeitos neurocientíficos não viram requisitos técnicos.

## Risco que aceitamos

Proporções e vocabulário podem ser ajustados pelo retorno do autor. Não vamos instalar uma bateria de navegadores nem bloquear esta entrega por aparelhos indisponíveis. Sem garantia de desempenho físico, formatação ou paridade completa. O download solicitado pode ser bloqueado pelo navegador; há cópia manual.

## Risco que verificamos agora

Texto Unicode intacto ao reabrir; falha de gravação sem perder o rascunho; base corrompida preservada; conflito entre sessões; composição IME; restauração explícita; armazenamento indisponível. Uma única rodada curta, repetida apenas após correção relacionada. Auditoria ampla fica no fechamento.

## O que o autor estava deixando em aberto

A prioridade precisa ser uma capacidade concluída, não uma árvore bonita. Aparência futura, perfeição arquitetural e todos os utilitários não cabem no primeiro lote. A evidência no repositório deve mostrar escolhas e limites, com uma porta de saída para os textos. A autoria do projeto não depende de aparentar uma carreira de décadas: decisões rastreáveis, correções honestas e continuidade fazem parte do trabalho de um vibecoder que estuda.

Não há equipe fictícia executando: os papéis discutidos servem como perguntas de revisão, e o trabalho continua solo.
